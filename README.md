# Employee Management System

## Overview
A web-based Employee Management System developed using Spring Boot, Thymeleaf, MySQL, and Lombok.

## Features
- Add new employees
- View employee records
- Update employee details
- Delete employee records
- Search employees by name
- Store employee information in MySQL
- REST API endpoints for CRUD operations

## Technologies
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Thymeleaf
- Lombok
- Postman
- Git and GitHub

## Database Setup
1. Start MySQL using XAMPP or your MySQL installation.
2. Create a database named `employee_db`.
3. Configure the database username and password locally.
4. Run the Spring Boot application.

## Run the Application
Start the project using the Maven Wrapper if it exists, or run it through the IDE.

Website: http://localhost:8080/employees

REST API base URL: http://localhost:8080/api/employees

## Testing
The REST API can be tested using Postman. Database changes can be verified through phpMyAdmin or MySQL Workbench.
